# 🐙 What Is GitHub?

> Git is the engine. GitHub is the car — with a GPS, radio, and seat warmers.

---

## 🤔 The Problem GitHub Solves

Git is great — it tracks all your file changes locally (on your computer).

But what if you want to:
- **Share your project** with others?
- **Work together** with a friend in another city?
- **Show your work** to a potential employer?
- **Contribute to** a project someone else built?

Git alone can't do any of that. That's where **GitHub** comes in.

---

## ✅ GitHub = Git + The Internet + Collaboration Tools

GitHub is a website that:

1. **Hosts your Git projects online** — so they're always accessible, never lost
2. **Lets multiple people work together** — even if they're in different countries
3. **Shows a visual interface** — so you can see branches, commits, and history without typing commands
4. **Adds review tools** — so teammates can comment on each other's work before it's accepted
5. **Runs automatic checks** — so errors are caught before they cause problems

---

## 🏙️ Think of It Like a City

```
Git         = The rules of construction (how buildings are built)
GitHub      = The city itself (where all the buildings live)
Repository  = One building in the city
Branch      = A floor under construction
Commit      = A finished room
Pull Request = An inspection before a room is officially opened
```

## 💡 GitHub vs. Similar Platforms

GitHub is the most popular, but not the only option:

| Platform | Who uses it |
|---------|------------|
| **GitHub** | Most open-source projects, most companies |
| GitLab | Popular in enterprise/private companies |
| Bitbucket | Popular with Atlassian (Jira) users |

They all do similar things. GitHub just has the biggest community.

---

## 🌍 How Big Is GitHub?

- **100+ million developers** use it
- **372+ million repositories** hosted
- Most of the world's open-source software lives here
- Companies like Google, Microsoft, Apple, Netflix all use GitHub

---

## 🧭 Navigating GitHub — The Basics

When you open any repository on GitHub, here's what you see:

| Element | What It Is |
|--------|-----------|
| **Code tab** | Browse all the files in the project |
| **Issues tab** | Bug reports and feature requests |
| **Pull Requests tab** | Work in progress waiting to be merged |
| **Actions tab** | Automated workflows running in the background |
| **Branch dropdown** | Switch between branches |
| **Commit history** | See every change ever made |
