# 🔧 What Is Git?

> The invisible engine running underneath GitHub — and why it matters even if you never type a single command.

---

## 🤔 Start With a Problem

Imagine you're writing a long essay. You save it as `essay.docx`.

You make some changes. Save again. More changes. Save again.

One day, you realize the essay was better three versions ago — but you've been saving over the same file each time.

**You're stuck. Your old work is gone forever.**

This is the exact problem Git solves.

---

## ✅ Git = A Time Machine for Your Files

Git is a tool that automatically keeps track of **every single change** you've ever made to your files.

Not just the last save — **every save, ever**. Going back to the very beginning.

With Git:
- You can go back to any previous version of any file, any time
- You can see exactly what changed, when, and who changed it
- Multiple people can work on the same files at the same time without overwriting each other

---

## 🧠 How Does Git Actually Work?

Every time you tell Git "save my progress right now" (this is called a **commit**), it takes a snapshot of all your files at that moment.

Over time, it builds up a chain of snapshots — like a timeline:

```
Snapshot 1 → Snapshot 2 → Snapshot 3 → Snapshot 4 (now)
"First draft"  "Added intro" "Fixed typos" "Final version"
```

You can jump to any snapshot at any time. Nothing is ever lost.

---

## 💡 Git vs. GitHub — What's the Difference?

| | Git | GitHub |
|--|-----|--------|
| **What it is** | A program/tool | A website |
| **Where it runs** | On your computer | On the internet |
| **What it does** | Tracks file history | Hosts projects online + adds collaboration tools |
| **Needs internet?** | No | Yes |
| **Who made it?** | Linus Torvalds (2005) | GitHub Inc. (2008) |

**Simple rule:** Git is the engine. GitHub is the car around it.

---

## 🌍 Who Uses Git?

Basically everyone in the tech world:
- Software developers (it was designed for them)
- Data scientists
- Writers working on collaborative documents
- Game designers
- Anyone managing files that change over time
